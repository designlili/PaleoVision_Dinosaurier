# PaleoVision_Dinosaurier
IHK-Abschlussprojekt zur Analyse historischer Dinosaurier- und Fossilfunddaten. Datenprüfung und Bereinigung mit Python, Machine Learning mit Random Forest und interaktive Visualisierung in Power BI. Mit Fundqualitätsbewertung, wirtschaftlichem Ländervergleich und Budget-Simulator für die Expeditionsplanung 2027.
